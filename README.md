# WCGO — World Cup 2026 Predictions (Frontend)

This workspace contains a Vite + React + TypeScript frontend scaffold tailored for the World Cup 2026 predictions app. It includes:

- TailwindCSS-based design system with World Cup palette
- i18n (English & Vietnamese)
- Supabase client wrapper for auth/data
- Pages: Auth, Matches, Leaderboard, Admin

Quick start

1. Install deps: `npm install`
2. Run dev server: `npm run dev`
